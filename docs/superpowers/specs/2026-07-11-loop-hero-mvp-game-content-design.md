# Loop Hero MVP — 遊戲內容設計規格

> **版本**：0.1  
> **日期**：2026-07-11  
> **範圍**：方案 A — 精簡 MVP（1 職業、1 章、15 卡、5 建築、9 敵 + 1 Boss）  
> **狀態**：待審核

---

## 1. 設計目標

### 1.1 核心體驗

玩家不直接操控英雄移動或攻擊，而是：

1. **裝備管理** — 選擇掉落裝備、決定替換時機
2. **世界建造** — 在 Planning 模式放置卡牌，塑造環路危險度與獎勵
3. **營地建設** — 用遠征資源解鎖永久升級與新卡牌

### 1.2 MVP 成功標準

- 玩家能在 30 分鐘內理解核心 loop（出發 → 繞圈 → 放牌 → 撤退 → 建設）
- 至少 3 種可辨識的策略路線（保守農資源 / 平衡推進 / 高風險快攻 Boss）
- Tile combo 至少 2 組可被玩家「發現」並重複使用
- 通關第一章 Boss 後有明確的「再來一局」動機（解鎖內容或更高難度預告）

### 1.3 明確不做（MVP 範圍外）

- 多職業（Rogue、Necromancer）
- 多章節 / 多難度
- Golden 卡、Oblivion 卡、Crafting 系統
- 秘密 Boss、百科全書
- 線上功能

## 2. 世界觀與敘事

### 2.1 設定

世界在「大崩解」後只剩一條環形道路與無盡虛空。英雄在夢境與現實的邊界不斷行走，無法停下。玩家以「記憶碎片」重建曾經存在的一小片土地——每放下一張卡，既是獎勵，也是新的威脅。

### 2.2 第一章：虛空邊境

| 元素 | 描述 |
|------|------|
| 起點 | 營火（Cozy Camp）— 英雄每圈必經的安全點 |
| 目標 | 累積資源建設營地 → 擊敗 Boss「虛空守衛」 |
| 基調 | 荒涼、懷舊、風險與記憶交織 |
| 結局 | 擊敗 Boss 後，虛空裂開一條縫隙，預告第二章（不在 MVP 實作） |

### 2.3 文案語言

- UI 與遊戲內文案：**繁體中文**
- 程式碼、資料 ID、註解：**英文**

## 3. 核心系統規格

### 3.1 雙模式

| 模式 | 觸發 | 行為 |
|------|------|------|
| Adventure | 預設 | 英雄移動、戰鬥、日曆推進 |
| Planning | 玩家暫停（非戰鬥中） | 時間凍結；可放牌、換裝、查看狀態 |

### 3.2 環路（Loop）

- 初始環路：8 格道路，全為 **荒原（Wasteland）**
- 第 0 格固定為 **營火（Camp）**
- 英雄順時針自動行走，每格停留時間固定（可調參：`TILE_TRAVEL_MS = 800`）
- **Loop 計數**：每完整繞一圈 +1，影響部分 tile 效果（如營地治療）

### 3.3 日曆（Day）

- 日曆條在 Adventure 模式、戰鬥進行中填充
- 填滿 → 新一天開始，觸發：
  - 所有 Landscape 的「每日效果」（草地治療等）
  - 所有 Road/Roadside 的「按天刷新敵人」邏輯
- Planning 模式不推進日曆
- **Day ≠ Loop**：圈數與天數獨立計算

### 3.4 卡牌放置規則

| 區域 | 放置條件 | 說明 |
|------|----------|------|
| Road | 覆蓋環路上的 Wasteland 格 | 替換，不可疊加 |
| Roadside | 與道路 **touching**（四方向正交相鄰） | 不可放在道路上 |
| Landscape | 距道路 **至少 1 格**（八方向相鄰也算非法） | 虛空中的地貌 |
| Special | 同 Landscape | MVP 僅寶庫 |

**鄰接語意**：

- `touching`：四方向正交（上下左右）
- `adjacent`：八方向（含對角）— MVP 僅哥布林營地觸發條件使用

### 3.5 戰鬥

- 自動回合制：攻擊條填滿 → 攻擊最近敵人
- 多敵同格：全部參與戰鬥
- 戰鬥中不可進入 Planning
- 戰鬥結束掉落：裝備 / 卡牌 / 資源（依敵人表）

### 3.6 遠征結束與資源保留

| 結束方式 | 資源保留率 |
|----------|------------|
| 死亡 | 30% |
| 主動撤退（非營火格） | 60% |
| 撤退（站在營火格） | 100% |
| 擊敗 Boss 後撤退 | 100% |

### 3.7 Boss 計量條

- 每放置 1 張卡 +固定值（`BOSS_METER_PER_CARD = 8`）
- 計量滿 → 下次英雄經過營火時生成 Boss 於營火格
- MVP 不提供 Oblivion；玩家需自行控制放牌節奏

## 4. 英雄（Warrior）

### 4.1 基礎屬性

| 屬性 | 初始值 | 說明 |
|------|--------|------|
| HP | 100 | 生命 |
| Max HP | 100 | 可被 Landscape 加成 |
| Damage | 10 | 基礎物理傷害 |
| Defense | 5 | 減傷（flat） |
| Attack Speed | 100% | 攻擊條填充速度 |
| Evasion | 5% | 閃避 |
| Vampirism | 0% | 吸血 |
| Counterattack | 0% | 反擊機率 |

### 4.2 裝備槽

4 槽：**武器、盔甲、盾牌、戒指**

| 槽位 | 主屬性 |
|------|--------|
| Weapon | Damage |
| Armor | Max HP |
| Shield | Defense |
| Ring | 隨機副屬性 |

### 4.3 背包

- 上限 12 件
- 第 12 格被新掉落覆蓋時，舊裝備自動分解為資源

### 4.4 升級與 Trait

- 每累積 `XP_PER_LEVEL = 100` 升一級
- 每次升級三選一 Trait（從已解鎖池抽取）
- MVP 共通 Trait 池：8 個（見 §8）

## 6. Tile Combo 規則

MVP 實作以下 4 組（2 組核心 + 2 組進階）：

| ID | 條件 | 結果 | 效果 |
|----|------|------|------|
| COMBO-01 | Meadow touching 任意非 Meadow | 花開草地 | +3 HP/天 |
| COMBO-02 | 3×3 全為 Rock 或 Mountain | 山峰 | +48% Max HP；每 2 天生成 1 Harpy 於最近道路格 |
| COMBO-03 | Treasury 的 8 adjacent 格全佔用 | 空寶庫 | 每 3 天 1 石像鬼 |
| COMBO-04 | 場上 Village ≥ 2 | 強盜營地 | 自動生成於距 Village 最近的路邊格；每 2 天 1 強盜 |

Combo 判定時機：每次成功放牌後立即檢查。

## 14. UI 流程（MVP）

1. **主選單** → 開始遠征 / 營地
2. **營地** → 建造建築、查看解鎖
3. **遠征** → Adventure / Planning 切換
4. **Planning** → 左側手牌、右側裝備、中央地圖
5. **戰鬥** → 簡化 JRPG 視圖（血條 + 攻擊條）

game/
